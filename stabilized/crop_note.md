# 14.mp4 固定裁切说明

推荐使用：[14_stabilized_cropped.mp4](14_stabilized_cropped.mp4)。

- 裁切后分辨率：**2510 × 676**。
- 原稳像坐标系中的固定裁切框：左上角 **(37, 63)**；右、下边界（不含）为 **(2547, 739)**。
- 相对 2560 × 800 稳像画布：左侧裁 37、右侧裁 13、上侧裁 63、下侧裁 61 像素。
- 全部 **2901 帧**使用同一裁切框；保持 **30 fps、96.7 秒**，不缩放画面。
- 原始视频上下各约 38 像素黑边也在计算有效画幅时排除。

## 最大画幅的计算

逐帧识别与外部连通的黑边，在源图中为 Lanczos4 重采样保留 4 像素边界余量，
将有效像素范围映射到固定稳像坐标后，计算全部 2901 帧的交集。
在交集中求面积最大的轴对齐矩形，并要求宽、高为偶数，适配 H.264/yuv420p。
不限制宽高比。最终面积为 **1,696,760 像素**。

“最大”针对上述有效区域定义、固定轴对齐裁切、原稳像画布范围和偶数尺寸约束。
不要求偶数尺寸时的最大矩形为 2515 × 675；为了兼容常用播放器，输出采用偶数尺寸的最优解。
最大矩形算法已在 150 个随机小掩码上与穷举法比较，覆盖奇偶两种尺寸约束。

## 坐标与画质

裁切不改变像素比例，只引入固定偏移：

```
x_cropped = x_stabilized - 37
y_cropped = y_stabilized - 63
```

因此不会引入随时间变化的位置或缩放。每帧变换已验证上述坐标关系，
并保存到 `transforms_homography_cropped.npz`。
矩阵方向为裁切后的参考坐标到原片坐标；反向转换使用其逆矩阵。

裁切版直接从原始视频按已有稳像变换重采样并编码，避免对先前稳像 MP4 再次转码。
原音轨直接复制；原片和未裁切稳像版均保留。

裁切范围预览见 [crop_preview.jpg](crop_preview.jpg)，绿色框即固定输出范围。
逐帧公共有效区见 [crop_common_valid_mask.png](crop_common_valid_mask.png)。
编码和音轨验证结果见 `crop_verification.json`。
原稳像误差评估见 [处理报告.md](处理报告.md)；固定裁切不会改变几何残差，
但这里没有重新独立测量裁切版每个检查点的编码后误差。

复现命令：

```powershell
python crop_stabilized.py 14.mp4
```
